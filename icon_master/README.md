# icon_master/ — Uygulama İkonu Kaynak Görselleri

Uygulama ikonunun master (kaynak) görselleri. Saf asset — kod içermez.

## İçerik
- `master_1024.png`, `icon_1024.png` — 1024px master'lar
- `favicon.ico` — web/tarayıcı favicon
- Boyut merdiveni: `icon_16..icon_512.png` (iOS boyutları dahil: 20/29/40/60/76/83.5→167/180)

Bu master'lardan mobil (`../pf/`), launcher (`../launcher/app/icons/`) ve web ikonları türetilir.
Dağınık asset toplama: [`../tools/organize_resources.py`](../tools/README.md).
